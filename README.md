# Cuando el camino más corto no es el mejor: Simulación de Evacuación ante Inundación

Proyecto de simulación inteligente de evacuación en cuadrícula ante desastres naturales (inundaciones), donde el camino de menor distancia no necesariamente es el más seguro debido a factores de riesgo variable y zonas bloqueadas.

## Estructura Modular y Ramas de Desarrollo

| Integrante / Módulo | Nombre de la Rama | Archivo Principal |
| :--- | :--- | :--- |
| **Integrante 1 (Entorno y Escenarios)** | `feature/environment` | `environment.py` |
| **Integrante 2 (Algoritmos de Búsqueda)** | `feature/search-algorithms` | `search_algorithms.py` |
| **Integrante 3 (Métricas y Pruebas)** | `feature/metrics` | `metrics.py` |
| **Integrante 4 (Visualización y Notebook)** | `feature/visualizer` | `visualizer.py` y notebook |

## Ejecución de Pruebas Preliminares

python main_test.py
